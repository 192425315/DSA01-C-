# Smart Campus Bike Sharing Management System - Web App

## Technology
- C++11 backend HTTP server using Winsock
- HTML5
- CSS3
- JavaScript Fetch API
- No Node.js or external framework required

## Run on Windows

1. Install MinGW/GCC.
2. Open this folder in VS Code.
3. Double-click `run_web_app.bat`.
4. Open `http://localhost:8080` in your browser.

The supplied backend is designed for old MinGW/GCC versions such as GCC 4.9.2 and uses C++11, not C++17.

## Features
- Dashboard
- User registration
- Bicycle inventory
- Start and end ride
- Automatic fare calculation
- Ride comparison
- Utilization report
- Live refresh from the C++ backend
- OOP classes: User, Bicycle, RideSession, BikeSharingSystem
- Operator overloading in the C++ domain model
