# FinSight AI — Advanced Financial Portfolio Web App

## What this version gives you
A browser-based Review 2 prototype with a professional dashboard.

### Module 1 — Portfolio Management
- Single user profile
- Unlimited investments in one profile
- Stock, Mutual Fund, ETF, Bond, FD, Cryptocurrency and Other
- Add / Edit / Delete / Search / Filter
- All investments remain visible together

### Module 2 — Financial Analysis
- Total invested value
- Current portfolio value
- Profit/Loss
- Weighted portfolio ROI
- ROI comparison and ranking

### Module 3 — Risk & Smart Insights
- Risk classification by investment type
- Rule-based recommendation engine
- Risk distribution
- Transparent recommendation rules

### Visual dashboard
- Performance chart
- Asset allocation donut chart
- ROI chart
- Risk exposure bars
- Portfolio health indicators

## Run in VS Code
1. Extract the folder.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Recommended: install the VS Code extension **Live Server**.
5. Right-click `index.html` → **Open with Live Server**.
6. The application opens in your browser.

No Node.js, npm, database or C++ compiler is required for this UI prototype.

## Important
The current-price values are assumed/demo values for Review 2. The architecture is ready for a real market-data API later. Do not present the current values as live market prices.

All data is stored in browser localStorage, so your added investments remain after refreshing the page on the same browser/device.
